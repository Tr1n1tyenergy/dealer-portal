# PFI assets

Used by `src/lib/orders/pfi-pdf.ts` to draw the PFI exactly like Trinity's Odoo template
(`Sale PRO-FORMA Invoice - S01177.pdf`).

| File | What it is |
|---|---|
| `logo.png` | Trinity nrg logo, high resolution (supplied by Trinity) |
| `footer.png` | The footer band (company name, contacts, address) taken from the Odoo template |
| `lato-medium.woff`, `lato-bold.woff` | Lato 2.0 Medium and Bold, the template's fonts (from the `lato-font@3.0.0` npm package) |
